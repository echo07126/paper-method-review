# 技术栈 / 运行环境 / 部署方式

## 1. 技术栈清单

| 层 | 选型 | 版本要求 | 说明 |
| --- | --- | --- | --- |
| 后端语言 | Python | 3.11+（开发机 3.14；容器 3.12） | 类型注解 + Pydantic v2 |
| Web 框架 | FastAPI / Uvicorn | 最新稳定版 | 接口 + 静态文档（/docs） |
| 数据校验 | Pydantic / pydantic-settings | v2 | 请求、响应与内部对象模型 |
| 文档解析 | python-docx | 1.2+ | 一期 DOCX（样式、上标、表格） |
| 模型服务 | httpx + DeepSeek Flash（OpenAI 兼容） | — | 可插拔 `LLMProvider` |
| 存储 | SQLite（标准库 sqlite3）+ 临时目录 | — | 会话/报告 + 会话内的结构化正文；上传件与过期数据定期清理 |
| 前端框架 | Vue3 + TypeScript + Vite | 最新稳定版 | 单页应用，四页动线 |
| 前端状态/路由 | Pinia + Vue Router | 最新稳定版 | 会话与报告状态 |
| UI 组件 | 原生 Vue 组件 + CSS 变量 | — | 主题定制（主色青绿 #0E9F8A） |
| 反向代理 | Nginx（nginx-unprivileged 镜像） | alpine | 静态资源 + /api 代理 + 安全响应头 |
| 容器 | Docker / docker compose | 最新稳定版 | 后端与前端两个镜像 |
| 测试 | pytest / httpx TestClient | — | 46 项单元与契约测试 |

## 2. 选型依据（简述）

- **FastAPI + Pydantic**：接口契约清晰（全部接口声明 `response_model`），对象分层模型可复用为校验与文档；自动生成 OpenAPI。
- **规则引擎 + 可插拔模型**：方法学审查以确定性判据为主（可复现、零成本），模型只做语义补充（顾问模式），并通过抽象接口支持后续换模型。
- **SQLite + 临时目录**：一期单机演示足够，零运维；上传件与结构化正文仅在会话内暂存，可一键删除、会话过期即清除；报告含原文引用片段（便于定位与复核）。
- **Vue3 + Vite**：开发体验好、构建快；CSS 变量便于统一视觉。
- **Docker 非 root + Nginx 安全头**：可移植、最小权限，便于云上与本地同构部署。

## 4. 部署方式

### 4.1 本地部署（开发/演示）
```bash
# 1) 后端
cd paper-method-review/backend
cp .env.example .env            # 填入 DEEPSEEK_API_KEY 等
python -m pip install -r ../requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000    # 文档: /docs

# 2) 前端
cd ../frontend
npm install
npm run dev                     # http://127.0.0.1:5173
```

### 4.2 容器部署（一键起）
```bash
cd paper-method-review
cp backend/.env.example backend/.env   # 生产：APP_ENV=prod、DEBUG=false、DOCS_ENABLED=false
docker compose up -d --build
# 前端: http://<host>:8080   后端(容器内): http://backend:8000
```
- 后端镜像：`python:3.12-slim`，创建 uid 10001 非 root 用户运行，内置 healthcheck；
- 前端镜像：`nginxinc/nginx-unprivileged:alpine`，监听 8080，含 CSP / X-Frame-Options / Referrer-Policy 等安全头；
- 卷：`./data`（SQLite 与临时目录）、`./checklists`（只读挂载）。

### 4.3 在线演示地址

### 4.4 环境变量与配置说明（`backend/.env`）
| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `APP_ENV` | 环境标识（dev/prod） | dev |
| `DEBUG` / `DOCS_ENABLED` | 调试与接口文档开关（prod 必须关闭） | true |
| `ALLOWED_ORIGINS` | CORS 白名单（不可为 `*`） | http://localhost:5173 |
| `DEEPSEEK_API_KEY` | 模型密钥（仅服务端；`.env` 优先于系统环境变量） | — |
| `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` | 服务地址与模型 | https://api.deepseek.com / deepseek-flash |
| `LLM_DEFAULT_ENABLED` / `LLM_ADVISORY_ONLY` | 模型顾问默认启用 / 顾问模式 | true / true |
| `LLM_VERIFY_ENABLED` / `LLM_VERIFY_MAX_ITEMS` | 引用落地验证与单篇上限 | true / 6 |
| `MAX_UPLOAD_MB` / `MAX_PAGES` | 上传大小与页数上限 | 50 / 60 |
| `SESSION_TTL_HOURS` / `DATA_RETENTION_HOURS` | 会话有效期与数据留存 | 2 / 2 |
| `DEMOTE_ON_FIGURES` | 图表未解析时是否保守降级 | false |
| `DB_PATH` / `TEMP_DIR` / `CHECKLIST_DIR` | 存储与清单路径 | ./data/app.db 等 |

## 5. 安全与合规

| 项 | 措施 |
| --- | --- |
| 密钥管理 | 仅经环境变量/`.env` 注入；不入库、不进前端、不进日志；日志记录 Key 尾号便于审计 |
| 数据隐私 | 上传件随机命名落临时目录、结构化正文入 SQLite，两者均**仅在会话内暂存**；会话/报告可一键删除（DB + 文件 + 缓存），会话过期或重启自动清理；模型调用前明示"内容将发送至模型服务商，仅用于本次审查、不作为训练数据" |
| 越权防护 | 所有按 ID 读取强制会话条件，跨会话一律 404；令牌仅存哈希 |
| 上传安全 | 扩展名 + 魔数 + 大小 + 页数 + 压缩炸弹校验 |
| 限流 | 上传 20/min、审查 10/min、追问 120/min（会话 + IP 双桶，超限 429） |
| 生产守卫 | 非 dev 环境禁止 DEBUG 与公开 API Docs；CORS 通配符与凭据不可同用 |
| 上线前必做 | 8 项环境类检查（TLS/HSTS、安全组、生产 Key 轮换、备份与删除传播、日志轮转、监控告警、事件演练、镜像扫描），由发布门禁脚本自动拦截 |
| 核查记录 | 31 项安全控制点全部已实现，并提供自动核查脚本 `backend/scripts/security_audit.py` |
