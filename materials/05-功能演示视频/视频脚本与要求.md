# 功能演示视频：脚本与要求

## 1. 基本要求
- 成品命名为 `演示视频.mp4` 并放入本目录。
- 时长 3–5 分钟；1080p；画面清晰；关键操作配字幕；讲解与操作同步。
- 录屏范围：浏览器全屏（http://127.0.0.1:5173 或在线地址），隐藏无关窗口与个人信息。
- 演示数据：内置示例论文（自建脱敏，预埋典型问题）；不使用真实未脱敏论文。

## 2. 分镜脚本（时间轴）
| 时间 | 画面 | 讲稿要点 |
| --- | --- | --- |
| 0:00–0:15 | 首页/上传页 | 痛点：方法学缺陷导致退稿；一句话定位：给论文做方法学体检，问题可定位到原文 |
| 0:15–0:45 | 上传示例论文 → 解析预览 | 支持 DOCX；自动分章（题目/摘要/引言/方法/结果/讨论）；解析质量提示（识别不确定的标题、图表引用） |
| 0:45–2:20 | 点击「开始结构化审查」→ 报告页 | 17 条清单逐条判定；展示一条「严重」问题：点击后右侧原文高亮定位；展示判定依据与修改建议；演示筛选（问题/存疑/通过） |
| 2:20–2:40 | 报告中「存疑」区 + 追问抽屉 | 模型只做顾问：语义类结论进入「存疑」供人工复核；点「追问这条」跳转抽屉，可多轮追问或自由提问（如「这句该怎么改？」→「有推荐的写法吗？」） |
| 2:40–3:00 | 修改对比页 | 选择初稿/修改稿两份报告：问题数下降、已解决/保留/新增条目 |
| 3:00–3:20 | 切换展示：要素/统计（可选） | 展示解析出的要素（样本量、数据划分、检验、置信区间）与统计（检出率 100%、精确率 100%、定位 96%）；单篇成本约 ¥0.01–0.05 |
| 3:20–3:40 | 差异化 + 收尾 | 与现有工具对比：现有工具多为医学报告清单核对；本产品面向计算机/AI 实证研究，规则可复现 + 原文定位 + 可插拔扩展 |

## 3. 关键台词（可直接使用）
- "它不是让 AI 写读后感，而是把方法学知识变成 17 条可执行的检查项，逐条作用在论文结构上。"
- "每条结论都指回原文段落——点到哪、改到哪，一目了然。"
- "规则给出可复现的判定，模型只提供建议并标注为存疑，避免 AI 幻觉影响报告可信度。"

## 4. 录制前准备清单

- [ ] 录屏软件（1080p、60fps 或 30fps）与麦克风试音
- [ ] 脱敏确认：示例数据为自建/脱敏
