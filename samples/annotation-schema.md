# 评测样本标注规范（v0.1）

> 用途：为 AC-2（预埋问题检出率）与 AC-3（引用定位复核）提供「标准答案」。
> 每个样本 = 一份 DOCX + 一份同名字段的标准答案 JSON。

## 1. 样本字段

| 字段 | 说明 | 取值 |
| --- | --- | --- |
| sample_id | 样本唯一 ID | `synthetic-001` / `real-001` |
| title | 样本标题 | 文本 |
| type | 来源类型 | `synthetic`（自建预埋）/ `real`（真实论文改写） |
| source | 来源说明（real 必填） | 期刊/arXiv 链接、许可 |
| license | 许可 | `self-authored` / `CC-BY` / `CC-BY-NC` 等 |
| language | 语言 | `zh` / `en` / `mixed` |
| items | 预埋问题清单 | 见下 |

## 2. 条目标注字段

| 字段 | 说明 |
| --- | --- |
| checklist_item_id | 对应审查清单条目 ID（如 R-03） |
| severity_expected | 期望严重级 high/mid/low |
| anchor | 期望定位（至少给 paragraph_index；可加 sentence_index） |
| note | 预埋方式与判分说明 |

## 3. 判分口径（与需求 9.1 一致）

- **命中**：系统报告存在同 `checklist_item_id` 且 verdict=problem 的结论；若系统给出锚点，需落在期望锚点 ±1 句（段落级放宽为同段落）。
- **漏报**：标准答案中未被命中。
- **误报**：系统报出但标准答案未标注的条目（用于统计精确率）。
- **AC-2 检出率** = Σ命中 / Σ标准答案条目；同时给出精确率与按严重级分组的检出率。

## 4. 真实论文改写要求（real 类型）

1. 优先选择**开放许可**来源（CC-BY / 开放获取期刊 / arXiv 明确许可）。
2. 改写后不得逐字复用原文超过合理引用范围；以「保留方法学问题结构、重写表达」为准。
3. 在 `source` 记录原始链接与许可，并在 `note` 说明改写范围。
4. 涉及机构、人名、患者信息一律脱敏。
