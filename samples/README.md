## 样本组成

| 分组 | 用途 | 篇数 | 标准答案 |
| --- | --- | ---: | ---: |
| `fixtures/` | 自建受控规则夹具，含 1 篇负对照 | 5 | 42 |
| `real/` | 开放许可论文改写并脱敏 | 7 | 26 |
| `review` | 综述/理论论文，检查误报（blind-001/002） | 2 | 0 |
| `empirical` | 规范实证论文，检查误报（blind-003） | 1 | 0 |
| `planted` | 预埋缺陷论文，检查阳性召回（blind-004） | 1 | 14 |
| **合计** | | **16** | **82** |

同名标准答案位于 `ground_truth/`，JSON 格式见 [`annotation-schema.md`](annotation-schema.md)。

> **关于 `real/raw/`**：该目录保存用户提供的 4 篇**原始**论文，属非开放许可（`ground_truth/*.json` 中记为 `user-provided`），仅本地留档，已被 `.gitignore` 排除、**不进入仓库**。评测与盲测脚本默认使用 `real/` 下的**改写脱敏版**（`blind-001..004.docx`）；`raw/` 缺失不影响任何脚本运行。

运行方式：

```bash
# 默认：仅规则引擎
python backend/scripts/eval_ac.py

# 含 LLM 顾问判定，需要联网和模型 Key
python backend/scripts/eval_ac.py --llm

# 刷新自建 fixtures
python backend/scripts/make_samples.py
```

说明：

- fixtures 是受控短文本，只用于规则回归，不能代表真实论文难度。
- real 为公开论文方法/结果节选改写，指标仍偏乐观；最终以未见过的完整论文盲测为准。
- LLM 结果仅进入“存疑”顾问区，不计入问题召回。
