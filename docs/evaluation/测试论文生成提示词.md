# 测试论文生成提示词（用于盲测与规则验证）

> 用途：生成用于本系统评审的测试论文。分两种版本，建议各 1 篇；若只做一篇，优先 **版本 A**。
> - **版本 A｜自然实证论文**：不刻意预埋问题，用于**盲测**（看系统是否误报/漏报；标准答案由人工阅读论文给出）。
> - **版本 B｜预埋缺陷论文**：按清单植入问题，用于**规则阳性验证**（每条规则都应命中）。

---

## 一、通用格式规格（两版都遵守）

1. 文件：`.docx`（Word）。
2. 语言：中文正文；英文术语、英文参考文献可混排。
3. 篇幅：正文 3000–6000 字，约 8–15 页。
4. 标题：必须使用 Word 内置**「标题 1 / 标题 2」样式**（不要只加粗）。
5. 引用：正文用**真正的上标格式**标注 `[n]`、`[n-m]`、`[n,m]`（Word 的“上标”按钮），**不要**用普通文字的方括号。
6. 参考文献：≥15 条，编号连续（[1]…[n]），条目以 `[1] ` 开头；正文引用编号与文献表一一对应。
7. 公式：单独成段并编号 (1)(2)…。
8. 表格：3–4 个（建议：表1 数据集统计、表2 主结果、表3 消融、表4 超参范围），题注以「表1 …」开头。
9. 图：1–2 张（图1 方法框架、图2 结果对比），题注以「图1 …」开头。
10. 章节结构（建议）：摘要＋关键词；1 引言；2 相关工作；3 方法（3.1 数据集与预处理、3.2 模型、3.3 训练细节与超参数搜索、3.4 评价指标）；4 实验（4.1 数据划分、4.2 基线方法、4.3 主结果、4.4 消融实验、4.5 统计检验与置信区间）；5 讨论与局限；6 结论；参考文献。
11. 主题：计算机/AI 实证研究（图像分类、医学影像、文本分类、时间序列预测、推荐系统等任选）。

## 二、内容要素要求（用于覆盖 17 条检查项）

生成时请**显式写出**以下信息（自然实证版本应尽量齐全）：

| 检查项 | 论文中应出现的内容 |
| --- | --- |
| R-01 研究目标 | 引言末尾明确研究问题/目标（如“本文旨在…”） |
| R-02 样本量依据 | 样本量（如 1,200 例）＋功效分析或数据可得性说明、纳入/排除标准 |
| R-03 数据划分 | 训练/验证/测试比例（如 7:1:2）或分层 5 折交叉验证；说明是否固定随机种子 |
| R-04 基线对比 | ≥2 个近期公开基线＋1 个经典方法，并说明选择依据 |
| R-05 消融实验 | 对提出的关键模块做有/无对照 |
| R-06 评价指标 | 与任务匹配的指标（准确率/AUC/F1/RMSE…）＋选择理由 |
| R-07 统计检验 | 配对 t 检验 / Wilcoxon 等，说明检验对象与前提 |
| R-08 多重比较 | 多数据集/多模型比较时说明校正方法（Bonferroni/Holm/FDR） |
| R-09 效应量与区间 | 报告 95% 置信区间或效应量 |
| R-10 重复与方差 | 独立重复 ≥3 次，报告均值±标准差 |
| R-11 结论外推 | 结论限定适用边界（不要写“普遍适用”） |
| R-12 超参数依据 | 搜索空间范围＋搜索方法（网格/随机/贝叶斯）＋最终取值依据 |
| R-13 预处理 | 归一化/标准化、数据增强、类别不平衡处理 |
| R-14 可复现 | 随机种子（如 42）、代码/数据可得性说明 |
| R-15 局限 | 局限性/未来工作/伦理与合规边界 |
| R-REF-01/02 | 引用编号与文献表一一对应；有「参考文献」章节 |

## 三、版本 A 提示词（自然实证论文，用于盲测）

> 直接复制以下内容使用；把【】中的主题替换成你想要的方向。

请生成一篇**中文实证研究论文**的 Word 文档（.docx），主题为【医学影像分类 / 文本分类 / 时序预测 等任选】，题目自拟。硬性要求：

1. **结构**：摘要＋关键词；1 引言；2 相关工作；3 方法（3.1 数据集与预处理、3.2 模型结构、3.3 训练细节与超参数搜索、3.4 评价指标）；4 实验（4.1 数据划分、4.2 基线方法、4.3 主结果、4.4 消融实验、4.5 统计检验与置信区间）；5 讨论与局限；6 结论；参考文献。
2. **必须写清**：数据规模与纳入排除（含样本量依据或功效分析）；训练/验证/测试划分比例（或分层 5 折交叉验证）；≥2 个近期基线与选择依据；关键模块的有/无消融；与任务匹配的指标及理由；配对 t 检验或 Wilcoxon 检验方法；独立重复 ≥3 次并给出均值±标准差；95% 置信区间或效应量；多数据集比较的多重比较校正；超参数搜索范围与选择依据；类别不平衡处理；随机种子（如 42）与代码/数据可得性；结论适用边界与局限性。
3. **格式**：标题用 Word「标题 1/标题 2」样式；正文引用用**真正的上标** `[n]`/`[n-m]`/`[n,m]`；参考文献 ≥15 条且编号连续、与正文一一对应；含 3–4 个表格（表1 数据集统计、表2 主结果、表3 消融）与 2 张图（图1 框架、图2 结果），题注以「表1/图1」开头；公式单独成段并编号。
4. **数值自洽**：各划分样本数之和等于总数；均值±标准差与显著性结论一致；不要编造与表格矛盾的数值。
5. 篇幅 3000–6000 字。

## 四、版本 B 提示词（预埋缺陷，用于规则阳性验证）

> 在「版本 A 提示词」基础上，**追加**下面这段（按需选择要植入的条目；建议一次植入 8–12 条，避免互相掩盖）：

请在论文中**故意植入**下列问题（其余部分保持规范、数值自洽）：

| 编号 | 植入方式 |
| --- | --- |
| R-01 | 只写研究背景，不明确研究问题/目标 |
| R-02 | 只写“共 1,200 例”，不写样本量依据/功效分析 |
| R-03 | 写“在验证集上通过网格搜索调参，并在测试集上评估”，或干脆不描述划分方式 |
| R-04 | 只与 1 个基线比较，且不说明基线选择依据 |
| R-05 | 声称提出“改进的注意力模块”，但全文无消融实验 |
| R-06 | 提出模型但不报告任何性能指标（或只报与任务不匹配的指标） |
| R-07 | 报告 `p<0.05`，但不说明用了什么检验方法 |
| R-08 | 在 3 个数据集上比较 4 个模型，但未提及多重比较校正 |
| R-09 | 只报均值，不报置信区间/效应量 |
| R-10 | 只报单次运行结果，不提重复次数与方差 |
| R-11 | 结论写“该方法普遍适用，可推广至各类任务” |
| R-12 | 只列超参数取值（如 lr=1e-4、batch=32），不写搜索范围与依据 |
| R-13 | 全文不提归一化/标准化/数据增强/类别不平衡处理 |
| R-14 | 不写随机种子、代码与数据可得性 |
| R-15 | 不写局限性/未来工作 |
| R-REF-01 | 正文出现上标 `[99]`，但参考文献表没有 [99] |
| R-REF-02 | 删除整个「参考文献」章节（**与 R-REF-01 二选一**，建议分成两篇做） |

## 五、交付与验收

- 交付：DOCX 文件（可放到 `paper-method-review/samples/real/raw/`，或直接给我路径）。
- 我方验收流程：解析质量（章节/角标/文献/表格/图）→ 逐条判定 → 人工标准答案 → 盲测报告（命中/漏报/误报 + 原因）。
- 注意：如果使用 AI 生成论文，请**人工核对数值自洽与引用编号**；本系统会对“悬空引用”“划分不清晰”“结论外推”等直接给判定。
