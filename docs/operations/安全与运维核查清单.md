## 2. 设计上的刻意取舍（非缺失，需环境配合）

| 项 | 说明 |
| --- | --- |
| HSTS 默认注释 | 仅在 HTTPS 终止后开启；纯 HTTP 演示环境开启会把 `localhost` 锁死。生产须启用（`frontend/nginx.conf` 已备注释开关） |
| API Docs 生产关闭 | 由 `guard_production()` 强制：`APP_ENV != dev` 且 `DOCS_ENABLED=true` 时**启动即报错** |
| DEBUG 生产关闭 | 同上强制 |
| 账号体系 | 一期匿名会话（免登录体验）；二期引入账号与跨设备历史 |
| 图像内部数据 | 图内数值由 L3 视觉识读（P2-3）产出**存疑线索**，不计入问题数；规则模式仍不解析图内数据 |
| 视觉识读成本 | 图片按张计费，受 `LLM_VISION_MAX_IMAGES`（默认 4）与 `LLM_VISION_ENABLED` 约束；仅启用模型顾问时触发 |

| # | 事项 | 验收标准 |
| --- | --- | --- |
| 1 | ⬜ TLS 证书 + 强制 HTTPS 跳转 + 开启 HSTS | `curl -I https://域名` 返回 301→https，响应头含 `Strict-Transport-Security` |

| 4 | ⬜ 备份与删除传播 | 正文仅在会话内暂存；如需留存报告则加密备份，且删除请求需覆盖备份 |
| 5 | ⬜ 日志轮转与保留 ≤30 天 | logrotate 或容器日志驱动，限制大小与保留期 |
| 6 | ⬜ 监控告警 | 健康检查、5xx 率、429 限流次数、模型失败率、磁盘使用率 |
| 7 | ⬜ 事件响应演练 | 密钥泄漏/被刷/数据误删三种场景各演练一次并留档 |

## 4. 运维 SOP（常用命令）

```bash
# 本地开发
cd paper-method-review/backend && python -m uvicorn app.main:app --port 8000
cd paper-method-review/frontend && npm run dev

# 容器化部署（生产）
cd paper-method-review
cp backend/.env.example backend/.env   # 填入生产密钥、APP_ENV=prod、DEBUG=false、DOCS_ENABLED=false
docker compose up -d --build
docker compose logs -f backend

# 健康检查 / 清理 / 文档同步
curl http://127.0.0.1:8000/api/v1/health
```
