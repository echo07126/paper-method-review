## 1. TLS 证书 + HTTP→HTTPS 跳转 + 开启 HSTS

**动作**
1. 申请证书（推荐 ACME，如 certbot；或用云厂商证书）：
   `certbot certonly --nginx -d your-domain.com`（或上传云证书到 `/etc/nginx/certs/`）。
2. nginx 增加 443 server 块，80 端口 301 跳转到 https。
3. 打开 `frontend/nginx.conf` 中已备好的 HSTS 注释项：
   `add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;`
4. 重新加载：`nginx -s reload`。

**验收**
- `curl -I http://your-domain.com` → `301` 且 `Location: https://...`
- `curl -I https://your-domain.com` → `200`，响应头包含 `Strict-Transport-Security`

## 2. 安全组最小开放（仅 443，DB/data 不暴露）

**动作**
1. 云安全组仅放行 **443**（80 仅用于跳转）；SSH（22）限制来源 IP 或改用跳板机/Bastion。
2. 确认容器端口只绑定本地回环（当前 compose 已绑定 `127.0.0.1`）：后端 8000、前端 8080 不直接暴露公网。
3. 确认 `data/`（SQLite 与临时目录）不在任何静态目录下、不通过 nginx 暴露。
4. 关闭不必要的服务与端口：`ss -lntp` 逐项核对。

**验收**
- 外网扫描仅 443（+受限的 SSH）开放；`data/` 路径无法通过 HTTP 访问（返回 404）。

## 3. 生产独立 Key + 90 天轮换

## 4. 备份与删除传播（正文仅在会话内暂存）

**动作**
1. 一期正文**仅在本次会话内暂存**：原始 DOCX 落 TEMP_DIR（随机文件名），解析后的结构化正文入 SQLite documents.ir_json；两者随会话过期、purge 或服务重启清除。确认 TEMP_DIR 与过期会话清理任务生效。
2. 如需保留报告：SQLite 文件加密备份（如 `sqlite3 .backup` + 加密存储），并设置保留期。

**验收**
- purge 后 `sessions/documents/reports` 无残留、临时目录不存在；备份恢复演练通过。

## 5. 日志轮转与保留 ≤30 天

**动作**
1. 容器日志：配置 logging driver（如 `json-file` 的 `max-size=10m`、`max-file=5`）或在 compose 中加 `logging:` 段。
2. 应用日志：logrotate 配置（`daily`、`rotate 30`、`compress`），或应用侧按天切分。
3. 确认日志内容脱敏（已由 `core/logging.py` 的 RedactionFilter 保证），禁止记录正文/密钥。
4. 日志目录访问权限最小化（仅运维可读）。

**验收**
- 日志总量有上限、保留 ≤30 天；抽查日志无正文/密钥。
